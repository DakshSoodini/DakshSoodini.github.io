# dakshsoodini.github.io

Source for my personal website: **[dakshsoodini.github.io](https://dakshsoodini.github.io)**

I'm Daksh Soodini, a Class 12 student at Oakridge International School, Hyderabad. I work on helping small farmers in Telangana use less water.

## What's on the site

- **Project Paani:** a smart greenhouse on a government school campus where students learn water-efficient and organic farming.
- **IQL Research (PANI):** offline reinforcement learning for irrigation scheduling. Code: [smartirrigationresearch](https://github.com/DakshSoodini/smartirrigationresearch).
- **Provisional Patent:** a soil tension-activated irrigation emitter that waters without electronics.
- **Coding Projects & More:** other machine-learning projects and volunteering.

## How it's built

- **One page, no frameworks:** a single static `index.html` with hand-written HTML and CSS. A small script switches between the tabs. There's no build step, and the site is hosted on GitHub Pages.
- **Media:** photos and video live in `assets/`.
- **Search and AI discoverability:** `sitemap.xml`, `robots.txt`, `llms.txt`, and structured data (JSON-LD) inside the page.

To view it locally, open `index.html` in a browser.
